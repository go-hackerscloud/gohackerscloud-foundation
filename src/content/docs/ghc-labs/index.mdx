# GHC Labs — Move from theory to practical experience

**Foundation teaches concepts for free. GHC Academy provides additional guided career tracks and hosted practice under its own access terms.** This page introduces the lab experience; it does not itself provide a subscription or launch a runtime.

GoHackersCloud's browser-based lab approach helps learners work through authorized security scenarios using prepared environments where a track includes a lab. Examples from the broader Academy offering include Kali, deliberately vulnerable web applications, API targets, cloud-oriented simulated scenarios and container exercises. The actual environment and available tools depend on the selected lesson and membership.

## What students do

```text
Foundation Concepts
       │
       ▼
Choose an Academy Track ─► Read Objectives and Safety Scope
       │
       ▼
Access Authorized Lab ─► Guided Terminal / Desktop (when available)
       │
       ▼
Collect Evidence ─► Explain Findings ─► End Session
```

**Good practice means more than running a command:** understand why it is used, what the expected observation means, what evidence supports your conclusion, and how you would communicate findings to a real team.

## Who benefits?

| Learner | Suggested next step |
|---|---|
| New to IT | Finish Foundation networking, Linux and security concepts before technical labs |
| Student / Career switcher | Start with introductory ethical hacking, web security or CompTIA-aligned learning |
| Cloud learner | Study cloud computing and IAM, then explore AWS Security or GHC Cloud Security |
| Developer | Explore Web, API and Application Security pathways |
| Working professional | Choose a relevant specialty or project and document evidence |

## How labs relate to courses and test preparation

Foundation provides the prerequisite concepts. A [self-paced course or learning bundle](/about-gohackerscloud/courses/) can help you work through a selected topic; [exam-style practice](/about-gohackerscloud/test-engine/) measures knowledge. GHC Labs is the separate environment for practical tasks and evidence-based exercises in supported Academy lessons. These products are not interchangeable, and access to one does not automatically unlock all the others.

For a complete view of the organization and the business-facing service offering, see [About GoHackersCloud](/about-gohackerscloud/). A student sandbox is not the same as a client security engagement.
