You explored the seven layers of the OSI Model:

1. Physical
2. Data Link
3. Network
4. Transport
5. Session
6. Presentation
7. Application

# How Everything Connects

The technologies you've learned work together to deliver secure and reliable communication.

```text
Users

↓

DNS

↓

Router

↓

Firewall

↓

VPN (if required)

↓

Load Balancer

↓

Application Server

↓

Database

↓

Response Returned
```

This architecture is commonly found in modern enterprise and cloud environments.
