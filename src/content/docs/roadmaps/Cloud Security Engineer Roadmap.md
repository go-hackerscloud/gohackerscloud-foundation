Welcome to the **Cloud Security Engineer Career Roadmap**.

This roadmap shows you how to progress from foundational IT knowledge to practical cloud security engineering skills.

## What You Will Learn

- IT and networking fundamentals
- Linux and Windows fundamentals
- Cloud computing
- AWS, Azure and Google Cloud fundamentals
- Identity and Access Management
- Cloud network security
- Logging and monitoring
- Vulnerability management
- Container and Kubernetes security
- DevSecOps fundamentals
- Governance, risk and compliance

## Recommended Journey

**Foundation → Cloud Fundamentals → Cloud Security → Hands-on Labs → Enterprise Projects**

Your first goal is to build strong fundamentals before moving into advanced Cloud Security Engineering.

## Start Here

Complete the **GoHackersCloud Foundation** learning path first.

After completing the Foundation curriculum, you will be ready to progress into the Cloud Security Engineer career track.
