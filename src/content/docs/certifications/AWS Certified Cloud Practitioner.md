The **AWS Certified Cloud Practitioner** certification provides foundational knowledge of AWS Cloud concepts, services, security, architecture and pricing.

## Who Is This For?

This certification is suitable for:

- Students entering cloud computing
- IT beginners
- Career switchers
- Professionals working with AWS
- Learners preparing for advanced AWS certifications

## What You Should Learn

Focus on understanding:

- Cloud computing concepts
- AWS global infrastructure
- Core AWS services
- AWS security
- Shared Responsibility Model
- Identity and Access Management
- AWS pricing
- Billing and support

## Recommended Learning Approach

Use the following sequence:

**Learn → Understand → Practice → Review → Test**

Avoid simply memorising AWS services.

Your goal should be to understand **why a service exists and when an organisation would use it**.
