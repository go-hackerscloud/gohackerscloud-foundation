## Core technical and professional concepts

### Fundamental principle

Variables, types, functions, loops and error handling structure understandable scripts.

### Practical distinctions

JSON represents API and log data; validate field presence and types.

### How teams use it

Automation should be tested with synthetic inputs, scoped credentials and reversible actions.

### How to show evidence

A script with no input validation can fail silently or expose secrets in debug logs.

## Real interview scenario

A team needs a script that counts HTTP 500 responses in a synthetic CSV or JSON log. The candidate describes parsing, errors, tests and expected output.

**Answer structure:** restate the requirement; identify scope, constraints and risk; choose a test or decision; verify evidence; communicate the outcome.

## Guided preparation exercise

1. Write pseudocode that counts error status codes.
2. Show what should happen with a missing field.
3. Describe two unit tests and one error case.
4. Avoid printing credentials or personal data.

Use only your own equipment, public documentation and authorized or synthetic environments. If you have only studied a technology, describe it accurately as study experience.
