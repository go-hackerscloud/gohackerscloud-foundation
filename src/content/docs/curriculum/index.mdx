## How to use the catalogue

- **Start at Module 00** if you are completely new or prefer a guided sequence.
- **Go in order through Modules 01–06** to build broad IT foundations.
- **Explore Modules 07–11** to understand cloud, cybersecurity, identity, cryptography, web and API concepts.
- **Study Modules 12–15** to develop an enterprise perspective and workplace skills.

The module cards open the first lesson. Expand the module entries in the full syllabus above to jump directly to any published lesson, assessment, lab or runbook.

## What completion means

Lessons, summaries and assessments are provided as learning resources. Completing a Foundation module does **not automatically award an industry certification**, create a formal credential or provision hosted lab access.
