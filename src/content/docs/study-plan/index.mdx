This is an **example schedule** for building conceptual familiarity and independent practice—not a guaranteed timeline, job outcome, certification or access plan for hosted labs.

Aim for a few consistent study sessions each week. If a concept is new, spend longer on it.

<FoundationGuidedNextSteps variant="plan" />

| Week | Foundation focus | Small independent practice |
|---|---|---|
| 1 | Orientation + IT fundamentals | Draw a basic computer/system diagram |
| 2 | Networking fundamentals | Map DNS, IP routing and HTTPS in a request |
| 3 | Linux fundamentals | Practise safe shell navigation and file permissions |
| 4 | Windows fundamentals | Summarize user accounts and system tools |
| 5 | Programming fundamentals | Write or explain a short Python script |
| 6 | DevOps and version control | Document a simple Git workflow |
| 7 | Cloud computing fundamentals | Compare service models and shared responsibility |
| 8 | Cybersecurity fundamentals | Create a simple asset–risk–control table |
| 9 | IAM and cryptography | Sketch authentication vs. authorization and encryption concepts |
| 10 | Web and API fundamentals | Describe a browser-to-server/API request |
| 11 | Security operations + professional skills | Write a sample alert summary |
| 12 | AI fundamentals + enterprise GRC | Explain an AI use case and a basic risk treatment |

## Your weekly routine

1. **Read** the relevant lessons and write a five-line summary.
2. **Sketch or practise** one concept on a system you control.
3. **Review** the corresponding module questions or assessment.
4. **Reflect** on what is still unclear and revisit it.
5. **Save** your notes before moving on.

The original [90-day learning plan](/foundation/gohackerscloud-foundation/00-welcome-to-gohackerscloud/12-90-day-learning-plan/) offers additional motivation and study habits. Where it refers to hosted labs, runbooks or advanced projects, treat those as optional future activities; they are not required for free Foundation access.

## What next?

After exploring these subjects, choose a domain to deepen: networking, IT systems, cloud, security, DevOps, AI or governance. The separate [Academy](https://academy.gohackerscloud.com/) provides additional structured career tracks and hosted practice under its own access terms.
